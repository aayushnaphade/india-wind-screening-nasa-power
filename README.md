# Wind resource screening of 60 Indian cities from hourly NASA POWER data

Reproducibility package for a screening study of the wind resource at 60 Indian
cities: data audit, 100 m wind-power density (WPD), Weibull statistics, a
screening capacity factor (CF), diurnal and directional structure, wind droughts
and the effect of spatial aggregation, and a chronological machine-learning
benchmark with feature attribution.

Every figure, table and number reported in the study is regenerated by two
scripts from the frozen data snapshot in `data/raw/`.

## Key results

| Quantity | Value |
|---|---|
| Hourly records audited (60 cities, 1 Jan 2024 – 13 Sep 2026) | 1,421,280 (1,419,840 usable) |
| Mean 100 m wind speed / WPD | 5.46 m s⁻¹ / 157.7 W m⁻² |
| City WPD range | 27.6 W m⁻² (Dehradun) – 272.2 W m⁻² (Bhuj) |
| Weibull shape k (maximum likelihood) | 1.97 – 2.96; Weibull-implied WPD within 2.3 % of hourly mean |
| Screening CF (generic, density-corrected turbine) | 13.3 % mean; 23.4 % at Bhuj; 6.3 % (Oct) – 27.8 % (Jul) nationally |
| Wind-drought days (daily CF below city 20th percentile) | 45.8 % of October days, 8.0 % of July days; longest single-city event 44 days |
| Days with CF < 5 % | 30.7 % for the median city vs 7.2 % for the all-India average |
| Daily CF correlation, north vs south | r = −0.03 |
| Best ML model (2026 test, 367,200 h) | Random forest: RMSE 154.6 W m⁻², MAE 82.7 W m⁻², R² = 0.536 |
| Gain over 24 h persistence | about 5 % in RMSE, 9 % in MAE; RF beats persistence at 45 of 60 cities |

## Reproduce

```bash
git clone https://github.com/aayushnaphade/india-wind-screening-nasa-power.git
cd india-wind-screening-nasa-power
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python scripts/wind_only_analysis.py       # core screening + ML benchmark
python scripts/wind_extended_analysis.py   # Weibull, CF, diurnal, roses, droughts, attribution
```

Runtime is a few minutes on a laptop (the random-forest fits dominate). Outputs are
written to `figures/` and `tables/`; the committed copies are the published versions,
so `git diff --stat` after a run shows whether anything changed.

Verified on Python 3.14.2 with the pinned versions in `requirements.txt`. All random
steps use fixed seeds. Re-running reproduces every table cell; the only differences
seen are in the last floating-point digit (~1e-14) of a few per-city scores, caused by
the summation order of parallel tree fitting.

## Data

* **Source:** NASA POWER hourly point API (community `RE`, UTC), parameters
  `WS50M, WD50M, T2M, RH2M, PS` (plus `ALLSKY_SFC_SW_DWN`, unused here), 1 Jan 2024 –
  13 Sep 2026. NASA POWER meteorology is derived from the MERRA-2 reanalysis.
* **Integrity:** check the inputs with `sha256sum -c data/SHA256SUMS`.
* **Refreshing:** `python scripts/download_nasa_power.py --out data/fresh` downloads a
  new copy without touching the snapshot. NASA may reprocess recent months, so a fresh
  download can differ slightly; the snapshot is what the published results use.
* **Audit notes:** −999 fill values (only the final 24 h of each file for wind) are set
  to missing. Ahmedabad and Gandhinagar fall in the same POWER grid cell and have
  identical series; Gandhinagar is excluded from all aggregates.

## Method assumptions (stated so they can be changed)

* 50 m → 100 m by power law, α = 0.14 (`v100 = 1.102 v50`); sensitivity for α = 0.10–0.25
  is in `tables/wind_extended/summary.json`.
* Hourly air density from the ideal-gas law, ρ = p / (287.05 (T + 273.15)).
* Screening CF: speeds normalised to 1.225 kg m⁻³ (IEC 61400-12-1 style), then a generic
  curve with cut-in 3, rated 12 and cut-out 25 m s⁻¹; no wake, availability or electrical
  losses. Use it for relative ranking, not plant yield.
* Wind drought: daily mean CF below the city's own 20th percentile (Qu et al., *Nature
  Climate Change*, 2025); only the 987 days complete at every city are used.
* ML: target is 100 m WPD; concurrent wind speed is excluded; training on 250,000 rows
  sampled from 2024–2025 and testing on all of 2026. Observed weather stands in for a
  forecast, so scores are an upper bound.

## Limitations

The 0.5° × 0.625° grid smooths local speed-ups and misrepresents hill sites; a single
shear exponent ignores stability; October–December are covered by only two years. These
results are a first screen and need validation against Indian met-mast data before any
yield or investment use.
